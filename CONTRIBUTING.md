# Contributing

Thanks for contributing!

## How to contribute

1. Fork the repo.
2. Create a branch for your change.
3. Keep changes focused and add comments for non-obvious logic.
4. Test manually by opening `index.html` in a browser.
5. Open a pull request with a clear description and screenshots when UI changes are made.

## Style

- Keep HTML semantic and minimal.
- Prefer small, reusable CSS rules.
- Keep JavaScript readable and avoid unnecessary dependencies.

## Reporting issues

Please include:

- Steps to reproduce
- Expected vs actual behavior
- Browser and OS details
- Screenshots or short videos if relevant
